# 八维表演改写示例

## 示例 1：紧张→镇定（职场场景）

### 原始脚本
```
小连听到王总叫他，显得很紧张，有点不知所措。
```

### 八维展开
```
时间段：0.0-5.0s
人物目的：他想在领导面前维持得体，同时掩饰内心的慌乱
情绪变化：平静 → 听到名字 → 紧张 → 试图掩饰
台词触发词："小连" —— 拖长的尾音让他感到被审视
面部动作与AU：AU 4（眉毛微蹙）+ AU 20（嘴唇微绷）
目光和身体：目光快速扫视后避开，L2 动作（手指攥紧）
声音呼吸：呼吸变浅，有一个不自然的吞咽
结束状态与禁止反应：身体僵住，想后退但克制住了
```

### 改写后
```
小连听到"小连"二字的瞬间（0.0-0.3s），瞳孔微不可察地收缩了一下，
眉毛下意识地向中间聚拢（AU 4），但很快又强迫自己松开。
他的嘴唇微微绷紧（AU 20），嘴角试图维持礼貌的弧度却显得有些僵硬。
视线从王总脸上快速扫过，随即垂下落在地面，不敢对视。
右手无意识地紧了裤缝，指节微微发白（L2 动作）。
呼吸在喉咙里浅了一拍，喉结上下滚动了一次——他在吞咽紧张。
"王总？您怎么在这……"（尾音不自然地上扬，带着一丝掩饰不住的警觉）
脚尖朝后退的方向移了半寸，又停住了，双脚像钉在地上一样没有移动（禁止反应）。
最终他站在原地，肩膀微微内扣，身体重心悄悄后倾，
与王总之间拉开了一道看不见的防线。
```

## 示例 2：愤怒→克制（冲突场景）

### 原始脚本
```
王总很生气，但还是忍住了。
```

### 八维展开
```
时间段：0.0-4.0s
人物目的：他想维持体面，不让对方看到自己失控
情绪变化：愤怒 → 意识到场合 → 强行压制
面部动作与AU：AU 4（眉毛压低）+ AU 7（眼睑紧绷）+ AU 23（嘴唇紧抿）
目光和身体：瞪视→移开视线，L2（下颌紧绷，太阳穴青筋）
声音呼吸：呼吸粗重→深吸气→压平
结束状态与禁止反应：想拍桌但手停在半空，想吼但声音压平
```

### 改写后
```
王总的眉毛猛地压低聚拢（AU 4），眉心挤出两道深深的竖纹，
上眼睑紧绷（AU 7），眼神像刀子一样钉在对方脸上。
他的下颌咬紧，太阳穴处的青筋微微跳动（L2 动作）。
呼吸骤然变重，鼻息粗得像要喷出火来。
"你——"（声音从牙缝里挤出来，低沉得发颤）
他的手已经抬起来了，掌心朝下，眼看就要拍向桌面——
但在离桌面还有三寸的地方，停住了。
手指悬在半空，微微发抖。
他闭了一下眼睛（AU 43，0.3 秒），再睁开时，
眼神里的火被硬生生压了下去，只剩一层冰冷的壳。
"……没什么。"（声音突然变平，像一潭死水）
他慢慢放下手，指节因为用力而泛白，
但脸上已经什么表情都没有了。
```

## 示例 3：震惊→觉醒（发现真相）

### 原始脚本
```
小连看到硬币上的天平图案，很震惊，然后决定了。
```

### 八维展开
```
时间段：0.0-8.0s
人物目的：他想理解眼前的一切，然后做出选择
情绪变化：困惑 → 震惊 → 挣扎 → 清明
面部动作与AU：AU 5（上眼睑提升）+ AU 25（嘴唇分开）→ AU 4（眉毛聚拢）→ AU 12（嘴角微紧）
目光和身体：焦点从硬币移到虚空→重新聚焦→坚定
声音呼吸：屏息→倒吸凉气→深长呼吸
结束状态与禁止反应：想逃避但选择了面对
```

### 改写后
```
小连的瞳孔骤然收缩（0.0-0.2s），上眼睑不自觉地提升（AU 5），
嘴唇微微分开（AU 25），像是要说什么却发不出声音。
硬币上"天平"的图案在应急灯的绿光下泛着冷硬的光泽，
他的视线死死钉在上面，焦点实得像要用目光把图案烧穿。

呼吸在喉咙里猛地一滞（0.3s），随后倒吸一口凉气——
"嘶"的一声，细微但清晰。

他的眉头慢慢聚拢（AU 4），不是困惑，是某种更沉重的东西在压下。
脑海里那些碎片——茶餐厅里大爷的话、黑暗中那只精准的手、
腕上停在 9 点 15 分的表——突然全部拼合在一起，
像一幅拼图最后一块"咔"地嵌进缺口。

他闭了一下眼睛（AU 43，1 秒）。
再睁开时，眼底那层游移不定的雾散了。

嘴角微微绷紧（AU 23），不是笑，是某种决定落地后的硬。
他深吸一口气，胸腔明显起伏，然后缓缓吐出——
这一口气吐完，先前那个犹豫、恐惧、不知所措的小连，
像是被一起吐出去了。

他想把硬币放回去（禁止反应）——手指已经捏住了硬币边缘，停了一秒，最终慢慢松开了。
但手指攥紧了硬币，指节泛白，棱角硌进掌心。
他没有放回去。
```

## 示例 4：伪装→暴露（谎言被揭穿）

### 原始脚本
```
王总笑着，但心里很慌。
```

### 八维展开
```
时间段：0.0-6.0s
人物目的：他想让对方相信自己，同时掩饰内心的恐慌
情绪变化：伪装自信 → 裂缝出现 → 强撑 → 濒临崩溃
面部动作与AU：AU 12（嘴角牵拉，无 AU 6）+ AU 4（眉毛微蹙）+ AU 45（频繁眨眼）
目光和身体：强作直视→游移→避开，L2（摸额头、擦汗）
声音呼吸：语速偏快→夹杂喘息→尾音发颤
结束状态与禁止反应：想逃但走不了，想笑但笑不出来
```

### 改写后
```
王总脸上咧开一个热络的笑容（AU 12），嘴角向两侧牵拉，
但眼睛没有参与——AU 6 缺失，眼角没有鱼尾纹，
这是一个只到嘴巴的笑。

"小连！哎呀，可算等着你了。"
"小连"二字拖得长长的，尾音上扬，带着刻意营造的亲近感，
但语速偏快，夹杂着快走后的粗重喘息——
他太急了，急到连伪装都来不及打磨。

说话间，他的视线飞快地扫过小连身后的车辆与四周角落（目光游移），
又迅速收回落回小连脸上，但停留的时间不超过一秒就再次移开。
他抬起空着的那只手背胡乱抹了一把额头（L2 动作），
汗珠在头顶日光灯下泛着油亮的反光，
没抹干净，新的汗珠又渗出来。

"天天加班，真够辛苦的。"
"辛苦"二字的尾音有一丝不易察觉的发颤，
像一根绷到极限的弦，再用力就要断了。

他想转身离开（禁止反应）——脚尖已经朝门口的方向转了十五度，又硬生生转了回来。
他想让笑容更自然些，但嘴角的弧度开始僵硬，
AU 4（眉毛微）不受控制地出现，
让那张笑脸看起来像一张快要裂开的面具。
```

## 改写检查清单

完成改写后，逐项检查：

- [ ] 每个情绪变化都有明确的触发点（不是凭空变化）
- [ ] 微表情（0.1-0.5s）与小动作（0.5-2s）有区分
- [ ] AU 编号使用准确，真假表情鉴别正确（如真笑必须有 AU 6）
- [ ] 目光描写具体（方向+焦点+变化），不是"眼神复杂"这类模糊词
- [ ] 身体动作有层级（L1-L4），不是只有大动作
- [ ] 呼吸模式与情绪匹配（紧张=浅快，悲伤=深长带颤）
- [ ] 台词演绎有具体参数（语速/音量/音色/停顿/气息）
- [ ] 有"禁止反应"（角色想做什么但没做）
- [ ] 结束状态有定格描写（身体+面部+与环境的关系）
- [ ] 八维内容整合后读起来流畅，不是机械罗列
